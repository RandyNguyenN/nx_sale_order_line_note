Order Line Internal Note

Write a private note on each Sale Order and Purchase Order line — discount reason, packaging instruction, quality check — right in the order lines, and never printed for the customer or vendor.

😓The Problem
  • ✗ A "note" line in the order is printed on the quotation — you cannot use it for internal remarks.
  • ✗ Remarks in the chatter are not tied to a line: which product was the special price for?
  • ✗ Deal details end up in spreadsheets or e-mails that nobody finds when the order is processed.
  • ✗ Purchasers have no place on the RFQ line for quality or price remarks about one item.
🎯The Solution
  • ✓ Internal Note column on Sale Order lines, edited directly in the line like any other field.
  • ✓ Same column on Purchase Order lines — RFQs and purchase orders.
  • ✓ Not added to any report — quotations, the customer portal and RFQs print exactly as before.
  • ✓ Optional column — each user shows or hides it from the column selector of the lines list.

Frequently Asked Questions

Will customers or vendors ever see the note?
No. The module does not add the field to any report or portal page, so quotations, sale orders, the customer portal, RFQs and purchase orders print exactly as in standard Odoo.
How is it different from adding a note line?
A standard note line (Add a note) is a separate line that is printed on the quotation. The Internal Note belongs to a product line and stays internal.
Can I hide the column?
Yes. It is an optional column, visible by default. Each user can untick Internal Note in the column selector at the right of the order lines header.
Is the note copied to the invoice?
No. The note lives on the Sale Order or Purchase Order line only; invoices and bills are not changed.
Is there anything to configure?
No. Install the module and the Internal Note column appears on Sale Order and Purchase Order lines. It depends only on Sales and Purchase.
